Excerpt from the KWorld / Jaycar XC4867 Windows driver package
("XC4867 Win 10/x64/EMBDA_x86_x64.inf", eMPIA BDA driver, dated 2020-04-06).

Reproduced here as short factual citation of hardware IDs, not redistributed as a
driver package. The binaries (emBDA*.sys, emOEM*.sys, *.ax, merlinFW.rom, installer)
are NOT in this repository.

Notes:
  * Every ID above is bound to the *same* driver instance ("USB28285"), i.e. eMPIA
    ships one code path for this whole family.
  * VID_EB1A&PID_8286 is the StarTech SVID2USB232, which mainline Linux already
    supports via EM28281_BOARD_STARTECH_SVID2USB232 (decoder = EM28XX_BUILTIN).
    Same driver instance => strongly suggests the eMPIA side is protocol-compatible.
  * "Iso" vs "Bulk" is the USB streaming transfer type. PIDs e609/e611 and e31d are
    the bulk variants; mainline has dev->analog_xfer_mode for that.
  * The package also ships merlinFW.rom, but the 2019 linux-media report for the
    older VS-USB2800 concluded no firmware load is involved for capture. Unverified
    for EM2980.
